## The entry

One sentence, in the cat's own voice — no apology, no confession, just
the most convincing case the cat can make for itself in the five seconds
after sweeping a glass off the table:

> I gave the glass five seconds to vacate my sunbeam, and it chose the floor, so legally this is its own decision.

## How it works

`main.py` (Python 3, standard library only) writes the sentence
deterministically to `entry.txt` (and to `/output/entry.txt` when that
directory is available), validating the gate first: UTF-8 text of 1 to
200 characters, a single line, not only whitespace.

```sh
python3 main.py
```
